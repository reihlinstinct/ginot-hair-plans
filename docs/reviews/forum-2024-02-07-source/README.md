# סיכום פורום 7.2.2024 - עותק ציבורי

מקור: [הסיכום באתר גינות העיר](https://www.ginothair.org.il/files/2024/02/7_2_24_%D7%A4%D7%95%D7%A8%D7%95%D7%9D_%D7%92%D7%99%D7%A0%D7%95%D7%AA_%D7%94%D7%A2%D7%99%D7%A8_%D7%A1%D7%99%D7%9B%D7%95%D7%9D__1_.pdf), [רשימת הסיכומים](https://www.ginothair.org.il/index.php?dir=site&page=articles&op=item&cs=2074). שמות המשתתפים, כותב הסיכום ושמות נוספים של אנשים הושחרו בעותק זה. תוכן התכנון לא שונה.

פריטים שקושרו לתכניות באתר לפי מספר תכנית שמופיע בסיכום: דוד המלך 8 (תכנית 101-0182667).

הטענות הן טענות מקור ולא ממצאים שאומתו. החלטת פורום להכין התנגדות אינה הוכחה שהוגשה. אין בעדכון זה הכנה או הגשה של התנגדות בשם אדם.

**הערת עריכה לעותק המושחר:** הוסר פרט אישי רגיש. פרטי התכנון והעדכון על השינוי בתפקיד נשמרו. להקשר המלא ראו את המקור המקושר.
