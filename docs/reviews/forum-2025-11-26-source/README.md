# סיכום פורום 26.11.2025 - עותק ציבורי

מקור: [הסיכום באתר גינות העיר](https://www.ginothair.org.il/files/2025/12/26_11_25_%D7%A4%D7%95%D7%A8%D7%95%D7%9D_%D7%92%D7%99%D7%A0%D7%95%D7%AA_%D7%94%D7%A2%D7%99%D7%A8_%D7%A1%D7%99%D7%9B%D7%95%D7%9D.pdf), [רשימת הסיכומים](https://www.ginothair.org.il/index.php?dir=site&page=articles&op=item&cs=2074). שמות המשתתפים, כותב הסיכום ושמות נוספים של אנשים הושחרו בעותק זה. תוכן התכנון לא שונה.

פריט שקושר לתכנית באתר לפי מספר תכנית שמופיע בסיכום: בן גמלא 6-8-10 (תכנית 101-1437755). פריטים אחרים בסיכום, המשתלה בצומת אורנים (מס' 1446319) ועדכון רחל אמנו 42-44, לא שויכו לתכנית באתר.

הטענות הן טענות מקור ולא ממצאים שאומתו. החלטת פורום להכין התנגדות אינה הוכחה שהוגשה. אין בעדכון זה הכנה או הגשה של התנגדות בשם אדם.
