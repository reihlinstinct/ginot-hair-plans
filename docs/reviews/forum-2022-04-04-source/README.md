# סיכום פורום 4.4.2022 - עותק ציבורי

מקור: [הסיכום באתר גינות העיר](https://www.ginothair.org.il/files/2022/04/4_4_22_sikum.pdf), [רשימת הסיכומים](https://www.ginothair.org.il/index.php?dir=site&page=articles&op=item&cs=2074). שמות המשתתפים, כותב הסיכום ושמות נוספים של אנשים הושחרו בעותק זה. תוכן התכנון לא שונה.

פריטים שקושרו לתכניות באתר לפי מספר תכנית שמופיע בסיכום: ימק"א כתר דוד (תכנית 101-0779546).

הטענות הן טענות מקור ולא ממצאים שאומתו. החלטת פורום להכין התנגדות אינה הוכחה שהוגשה. אין בעדכון זה הכנה או הגשה של התנגדות בשם אדם.
