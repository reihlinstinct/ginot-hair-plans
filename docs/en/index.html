Permit requests

Source: the Jerusalem municipality permit-data system. A permit request is NOT a deposited plan - objections to a request are filed according to the publication terms (section 149 of the Planning and Building Law) and the deadlines stated in the publication itself. Completed requests (closed or permit issued) are hidden by default. By default only objection-relevant requests are shown - open for objections or approaching publication - in the Ginot HaIr neighborhoods; the other groups are under "More groups", plus the "Also show outside the 7 neighborhoods" toggle. The raw source status is shown in every row. Requests with no known publication date stay visible and marked - a missing date is not evidence that the request is old or unpublished. A verified municipal publication is used for display grouping and the publication date even when the raw status has not caught up; it does not confirm an unknown objection deadline. The request number links to the case in the municipal permit-data system. The AI-review column links to an automatic summary when published; it is not an official document and does not file an objection.

Display groups:
More groups

The buttons filter by display groups, not by exact status. The "Publication / objection notices" group includes publication stages from the source and requests with a verified municipal publication, even if their source status differs. Requests in "advance paid" status are not moved into this group: their municipal publication shows in a separate group, "Municipal publication - needs review". A publication alone does not confirm that an objection can be filed now. To filter an exact status use the "All source statuses" list; the original status is kept in every row.
