Accessibility statement

The גינות העיר committee works to make this site accessible to the general public, including people with disabilities. The site aims to meet Israeli Standard 5568 for web accessibility (an adoption of WCAG 2.1) at level AA.

Draft machine translation, not yet reviewed by a native speaker.

Accessibility measures

  • Semantic markup and full keyboard operation, including the table filters.
  • Color contrast meeting level AA requirements.
  • Forms with labels and accessible names for selection controls.
  • Automated accessibility tests (axe, WCAG 2.1 AA) run on every site build.

Known limitations

  • The map is a visual component; its data is also available in the site's text tables.
  • Translations into languages other than Hebrew are machine-generated and marked as drafts.
  • Automated scans are not a manual accessibility audit; no manual or SI 5568 audit of the site has been performed.

Accessibility feedback

Found an accessibility problem or have a suggestion? Report it via the site's issue tracker and we will handle it promptly.
