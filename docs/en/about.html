About this site

This site collects public information about plans and permit requests relevant to the גינות העיר committee area in Jerusalem, and updates automatically. Updated: 2026-11-10.

Draft machine translation, not yet reviewed by a native speaker.

The site is an independent initiative of the committee and is not an official site of the Jerusalem Municipality, the Planning Administration or the Israel Land Authority. The information is for convenience only, is no substitute for the official sources and is not legal advice. The objection deadlines shown are estimates only - the binding deadline is set by the official deposit notices.

Data access (API)

The data is available as static files (JSON / Atom) for free use, with open CORS. There are no server-side queries - filtering happens on the client. All files update on every site refresh (a weekly refresh and manual refreshes).

FileContentStructure
data.jsonThe full dataset: plans, recent changes and permit requests {generated, rows[], changes[], permits[]} - Field names as received from iplan / the licensing data viewer
open.jsonOpen plans only (still in the planning process) {generated, definition, count, plans[]} - Each record includes in_objection_period (objection window open today)
feed.xmlAtom feed of new plans and changesAtom 1.0
badge/*.jsonEndpoints for shields.io badges (plan count, status breakdown, update date) {schemaVersion, label, message, color}

Privacy

The site shows data from public sources only. Fields identifying private stakeholders (for example stakeholders in permit requests) are removed in the processing pipeline and are not shown here, even though they are visible at the source.

Visit counting: the site uses Cloudflare Web Analytics to measure the number of visits only, without cookies, without storing IP addresses and without personal tracking. Free-text search is not sent: it is removed from the page address before the measurement is sent.

Usage statistics: the site collects aggregate, anonymous counters about searches and filters (which plans, streets and filters people search). A search is counted only when it exactly matches a value from the data itself; free text never leaves the browser. The counters are public and shown in the "Usage statistics" section on this page.
