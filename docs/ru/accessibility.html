Декларация доступности

Комитет גינות העיר работает над тем, чтобы этот сайт был доступен всем, включая людей с ограниченными возможностями. Сайт стремится соответствовать израильскому стандарту 5568 о доступности онлайн-информации (адаптация WCAG 2.1) на уровне AA.

Черновой машинный перевод, ещё не проверен носителем языка.

Меры по обеспечению доступности

  • Семантическая разметка и полное управление с клавиатуры, включая фильтры таблиц.
  • Контрастность цветов, соответствующая уровню AA.
  • Формы с подписями и доступными именами элементов выбора.
  • Автоматические проверки доступности (axe, WCAG 2.1 AA) при каждой сборке сайта.

Известные ограничения

  • Карта - визуальный компонент; её данные также доступны в текстовых таблицах сайта.
  • Переводы на языки, кроме иврита, созданы машинным переводом и помечены как черновики.
  • Автоматические проверки не заменяют ручной аудит доступности; ручной аудит или аудит по СИ 5568 не проводился.

Обратная связь по доступности

Нашли проблему с доступностью или есть предложение? Сообщите через систему отчётов сайта, и мы оперативно разберёмся.
