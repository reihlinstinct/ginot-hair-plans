О сайте

Этот сайт собирает публичную информацию о планах и заявках на разрешения, относящихся к району комитета גינות העיר в Иерусалиме, и обновляется автоматически. Обновлено: 2026-11-10.

Черновой машинный перевод, ещё не проверен носителем языка.

Сайт - независимая инициатива комитета и не является официальным сайтом мэрии Иерусалима, Управления планирования или Управления земель Израиля. Информация на сайте - только для удобства, не заменяет официальные источники и не является юридической консультацией. Показанные сроки возражений - лишь оценки; обязательный срок определяется официальными уведомлениями о депозите.

Доступ к данным (API)

Данные доступны как статические файлы (JSON / Atom) для свободного использования, с открытым CORS. Серверных запросов нет - фильтрация происходит на клиенте. Все файлы обновляются при каждом обновлении сайта (еженедельное обновление и ручные обновления).

Конфиденциальность

Сайт показывает данные только из публичных источников. Поля, идентифицирующие частных заинтересованных лиц (например, заявителей в заявках на разрешения), удаляются при обработке и здесь не показываются, хотя в источнике они видны.

Подсчёт посещений: сайт использует Cloudflare Web Analytics только для подсчёта числа посещений, без cookie, без хранения IP-адресов и без персонального отслеживания. Свободный текст поиска не отправляется: он удаляется из адреса страницы до отправки измерения.

Статистика использования: сайт собирает суммарные анонимные счётчики поисков и фильтров (какие планы, улицы и фильтры ищут). Поиск засчитывается только при точном совпадении со значением из самих данных; свободный текст никогда не покидает браузер. Счётчики публичны и показаны в разделе «Статистика использования» на этой странице.
